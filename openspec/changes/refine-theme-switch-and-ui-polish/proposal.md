## Why

上一轮改造解决了主题能力，但视觉结果与交互落点未达到预期：整体观感不够精致，主题切换入口与页面结构割裂，用户主观体验下降。需要进行一次“以体验质量为核心”的精修，将主题切换融入更自然的工具栏语义，并建立更稳健的视觉层级。

## What Changes

- 优化主题切换入口位置与形态，使其从“突兀控件”调整为与头部信息架构一致的工具操作项。
- 重构关键视觉层级（背景、主面板、分组标题、按钮、输入控件、提示反馈），提升克制感与专业感。
- 增加组件级状态细节（hover/focus/active/disabled）的一致性规范，减少“拼接感”。
- 优化深浅主题下的对比度与信息密度，确保既耐看又高可读。
- 清理上一轮过重或不协调的样式表达，避免“换皮但不协调”的 UI 体验。

## Capabilities

### New Capabilities
- `theme-entry-integration`: 定义主题切换入口在头部中的语义位置、交互方式与视觉融合规则。
- `ui-polish-refinement`: 定义主界面的高级视觉精修规范，覆盖层级、状态细节与一致性约束。

### Modified Capabilities
- （无）

## Impact

- 影响代码：`src/App.vue`、`src/style.css`。
- 影响范围：渲染层样式与主题控件交互呈现，不涉及 Electron 主进程与录屏逻辑。
- 依赖变化：无新增依赖，继续使用 Vue3 + CSS 变量体系。
- 风险点：样式精修涉及面广，需重点回归关键操作可达性与可读性。
