## Why

用户勾选“默认文件夹自动保存”后仍被弹出保存对话框，行为与文案承诺不一致，直接影响核心截屏体验。与此同时，默认目录仅文本展示不可点击，导致用户无法快速定位文件，增加操作成本。

## What Changes

- 修复自动保存路径分支逻辑，确保在满足条件时跳过保存对话框并直接写入默认目录。
- 明确自动保存失败时的回退策略：仅在写入失败或目录无效时提示并允许手动保存。
- 将“当前目录”展示改为可点击入口，支持一键打开默认保存文件夹。
- 补充与 Electron API 的文件夹打开能力对接（渲染进程调用预加载桥接能力）。
- 完善相关提示文案与状态反馈，减少“已开启自动保存却仍弹框”的困惑。

## Capabilities

### New Capabilities
- `default-save-folder-open`: 在已设置默认保存目录时，用户可点击目录文本并直接打开该文件夹。
- `auto-save-screenshot`: 开启自动保存后，截图保存应优先直存默认目录并仅在异常时回退手动保存。

### Modified Capabilities
- （无）

## Impact

- 影响代码：`src/App.vue`、`electron/preload.js`、`electron/main.js`（或主进程文件系统/壳层调用处）。
- 影响流程：截屏保存与默认目录交互。
- 依赖变化：无新增第三方依赖，基于 Electron 内置能力实现。
- 风险点：不同平台/权限下目录打开与写入失败处理需有明确兜底提示。
