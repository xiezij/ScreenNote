## Why

当前界面以紫黑渐变和高饱和强调色为主，虽然可用，但整体视觉辨识偏“模板化”，不符合长期使用的专业工具气质。新增主题切换并重构视觉体系可以同时提升可读性、个性化体验与产品质感。

## What Changes

- 新增主题切换能力，支持浅色与深色主题快速切换，并持久化用户偏好。
- 增加系统主题跟随策略：当用户选择“跟随系统”时，自动响应系统明暗模式变化。
- 将现有页面样式重构为语义化设计 token，统一管理背景、文字、边框、强调与状态色。
- 优化主界面视觉风格（头部、主面板、按钮、提示、滚动条等），去除紫黑主导和“AI 味”观感，转向中性、克制、工具型设计语言。
- 保持截屏、录屏、保存与转码等现有功能交互不变，仅做视觉与主题相关改造。

## Capabilities

### New Capabilities
- `theme-switching`: 提供浅色/深色/跟随系统主题切换、应用时机与偏好持久化能力。
- `ui-visual-refresh`: 定义主界面的新视觉规范与组件样式映射，确保在不同主题下保持一致的可读性与层级关系。

### Modified Capabilities
- （无）

## Impact

- 影响代码：`src/App.vue`、`src/style.css`、`src/main.js`。
- 影响范围：Electron 渲染层 UI 与主题状态管理。
- 依赖变化：无新增第三方依赖，基于现有 Vue3 与原生 CSS 变量实现。
- 风险点：样式重构涉及范围较大，需要验证截屏/录屏主流程在两套主题下无交互回归。
